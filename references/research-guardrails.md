# 科研警示与纠偏

这是按现象触发的检查，不是每项任务都要完成的审计表。普通问题在授权范围内自主纠正；涉及新增实验、协议、预算或方向变化时准备具体提案共同决定。暂停受影响的运行、比较或结论，继续独立且已授权的工作。

## 触发与处理

| 风险信号 | 应做的检查与处理 | 恢复推进的依据 |
| --- | --- | --- |
| 指标突然提升，或测试好得不合常理 | 查训练／验证／测试的真实样本身份和分组单位、重复样本、预处理拟合范围、未来信息与特权输入；核查指标实现和样本筛选变化。相关时查看历史样本暴露记录 | 提升来源可追溯；发现污染则标记受影响结果，修正方案共同决定，不能直接宣称方法有效 |
| 代码审查通过，但实际行为异常 | 在已授权检查内追踪一条真实输入到输出，核对张量、预处理、掩码、单位、归一化、权重是否确实加载、缓存是否对应本次配置；需要额外实验时先提案 | 有实际中间产物和预期行为的对应证据，不能只写“看起来没问题” |
| 本地修好了，服务器结果却不变 | 核查实际进程、工作目录、部署代码、配置、数据与权重身份；区分当前修复和已产出结果所用版本 | 运行身份与结果索引对应；不能用当前本地 HEAD 替代历史执行版本 |
| 新对话想“接着跑”或重启任务 | 先读交接，再查已有进程／作业、输出、检查点、锁和自动接续队列；旧时间戳不代表现在仍在运行 | 明确恢复、等待或重试条件，不开第二套相同任务，不覆盖现有结果 |
| 同一错误反复出现，却没有新诊断 | 停止同类盲目重试，保留最小失败证据，区分环境、接口、实现和研究假设；每次尝试说明检验哪个判断及停止条件 | 新尝试有可区分原因的证据目的，且仍在既定方案和预算内；改变实验语义则先讨论 |
| 指标不理想，开始换样本、种子、指标或预算 | 对照 `experiment/evaluation.md` 的现行版本；保留完整尝试与失败，探索分析和确认分析分别标注，不能只报告最好一次 | 采用原协议完整报告，或经讨论形成新版本；偏离与对应结果明确记录 |
| 新方法赢了，但对照条件不同 | 核对数据、初始化、训练／推理预算、搜索与规划调用、调参机会、权重来源；报告额外计算和资源差异 | 比较在主张要求的条件下成立，或明确限制结论；补充对照属于新实验时先讨论 |
| 损失下降、oracle 或单一诊断改善，就宣布机制成立 | 区分工程成功、代理指标、真实任务收益与因果机制；列出仍成立的替代解释及反证，结合跨种子或样本波动给出适当不确定性 | 结论强度与现有证据匹配；新增消融、重跑或确认实验先共同决定 |
| idea 听起来新，或论文标题像是支持主张 | 核查最近邻原文、发表状态和证据位置；摘要阅读与全文阅读、论文报告与本地复现、下载成功与阅读完成分别记录 | 未核实的新颖性和解释保持候选状态，引用能定位到实际来源，不把搜索不到当作不存在 |
| 文件越来越整齐，研究主线反而更难找 | 回到研究问题、当前主张和支持／反证，建立实验—代码—协议—原始证据—结论的映射；优先更新已有主要记录 | 当前入口能找到主线及证据；不为外观迁移活跃目录，不复制平行总纲 |
| 上下文变长、阶段结束或出现重要决策 | 当时更新 `handoff.md`：已完成、运行中及核验时间、不可直接重复的操作、下一步与待决定项 | 新对话可据文件恢复，并能区分已核验事实、历史状态和待核实项，不依赖聊天记忆 |
| agent 已交付，使用者却无法解释核心结论 | 区分交付、科学证据与理解状态；按 [学习与独立判断](learning-and-ownership.md) 选择必要的解释、预测或独立操作机会 | 根据用户实际表现记录理解，不以“继续”认定掌握，也不以测验阻断无关已授权任务 |

世界模型与具身项目还应在相关时检查时间粒度、动作语义、坐标与单位、oracle 可部署性，见 [领域专项](world-model-and-embodied.md)。

## 用真实问题改进警示

发现值得保留的问题时，在项目现有记录中简记：**触发现象、证据入口、已确认根因或尚存假设、处理结果、适用范围与重开条件**。失败和负结果也保留，不把未定位问题写成已解决。

项目特有路径、参数、阈值或一次实现失败留在该项目，先形成有依据的候选经验。经核实有通用价值并得到维护者采用后，才提炼进本文件；不把一个项目的统计门槛或偶然现象强加给所有研究。实际调用 skill 不自动授权修改或发布公共仓库。
